# 塔罗解牌助手

线下抽牌、线上辅助解牌的本地 Web 应用。

## 功能

- **牌义库**：78 张维特塔罗牌正逆位含义，支持搜索与筛选
- **牌阵库**：8 种预设牌阵，含坑位说明与解读技巧
- **录牌解读**：手动录入线下抽到的牌，获得结构化解读提示
- **模式分析**：大/小阿卡纳、元素分布、正逆位比例等
- **占卜日记**：保存问题、牌面与笔记，支持历史回看
- **AI 深度解读**（可选）：配置 OpenAI 兼容 API 后可用

## 快速开始

```bash
# 安装依赖
pip install -r requirements.txt

# 启动服务
uvicorn app.main:app --reload
```

浏览器访问 http://127.0.0.1:8000

## 使用流程

1. 点击「开始解读」，输入你的问题
2. 选择适合的牌阵
3. 用你自己的牌组线下抽牌
4. 在程序中逐坑位录入抽到的牌（含正逆位）
5. 查看结构化解读、模式分析与笔记

## AI 配置（可选）

在「设置」页配置 API Base URL、API Key 和模型名称。支持 OpenAI 及兼容接口。不配置时程序完全离线可用。

## 技术栈

- FastAPI + Jinja2 + SQLite
- 牌义与牌阵数据存储在 JSON 文件中
- 占卜记录存储在本地 SQLite 数据库
