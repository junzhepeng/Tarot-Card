# 塔罗解牌助手

线下抽牌、线上辅助解牌的本地 Web 应用。

## 功能

- **牌义库**：78 张维特塔罗牌正逆位含义，支持搜索与筛选
- **牌阵库**：8 种预设牌阵，含坑位说明与解读技巧
- **录牌解读**：手动录入线下抽到的牌，获得结构化解读提示
- **模式分析**：大/小阿卡纳、元素分布、正逆位比例等
- **占卜日记**：保存问题、牌面与笔记，支持历史回看
- **澄清牌**：解读结果页可为任意坑位追加澄清牌，生成原牌 + 澄清牌组合解读
- **应验追踪**：标记占卜分类与应验状态，记录事后回顾
- **历史筛选**：按关键词、分类、应验状态筛选历史记录
- **Markdown 导出**：一键导出完整解读报告
- **解读指南**：离线查阅花色、数字、宫廷牌与 30+ 术语
- **占卜对比**：两次历史记录左右对照牌面变化
- **自定义牌阵**：自建坑位牌阵，保存后可用于录牌
- **数据备份**：导出/导入 JSON 备份，换机可恢复
- **每日一牌**：每天记录一张牌与感受，时间线回顾
- **录牌优化**：牌名搜索、最近使用、右键收藏快捷选牌
- **AI 深度解读**（可选）：配置 OpenAI 兼容 API 后可用

## 快速开始

```bash
# 安装依赖
pip install -r requirements.txt

# 启动服务
uvicorn app.main:app --reload
```

浏览器访问 http://127.0.0.1:8000

## 使用流程

1. 点击「开始解读」，输入你的问题
2. 选择适合的牌阵
3. 用你自己的牌组线下抽牌
4. 在程序中逐坑位录入抽到的牌（含正逆位）
5. 查看结构化解读、模式分析与笔记
6. 若某坑位含义模糊，可点击「添加澄清牌」录入补牌并获得组合解读

## AI 配置（可选）

在「设置」页配置 API Base URL、API Key 和模型名称。支持 OpenAI 及兼容接口。不配置时程序完全离线可用。

## 技术栈

- FastAPI + Jinja2 + SQLite
- 牌义与牌阵数据存储在 JSON 文件中
- 占卜记录存储在本地 SQLite 数据库

## 牌面图片

78 张 RWS 牌图来自 [metabismuth/tarot-json](https://github.com/metabismuth/tarot-json)（公有领域 RWS 扫描件）。

首次克隆后若缺少图片，运行：

```bash
python scripts/download_card_images.py
```
